# 🛠️ BuildStudio IDE

BuildStudio is a powerful, native on-device Android Java IDE and compiler application. It lets you create, edit, compile, dex, package, sign, and install real Android APKs directly on your Android device without needing a PC.

## ✨ Features
- ⚡ **Full Toolchain On-Device**: Pre-bundled AAPT2, ECJ (Eclipse Compiler for Java), D8 dexer, and Zip/APK Signer.
- 📁 **Project Manager & Templates**: Empty Project, Floating Action Button, Fullscreen, and Navigation Drawer templates.
- 📝 **Code Editor**: Syntax highlighting, line numbers, file tree explorer, tabbed interface.
- 🤖 **Build AI Assistant**: Integrated AI chat to assist with Android code generation and debugging.
- 📱 **1-Click Build & Install**: Compiles and installs the generated APK directly on your device.

## 🚀 Automated CI/CD
Every commit pushed to `main` automatically triggers GitHub Actions to build the latest production APK and publish a release.
